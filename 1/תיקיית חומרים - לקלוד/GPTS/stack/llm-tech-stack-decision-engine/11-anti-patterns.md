# 11. Anti-Patterns

Avoid:

- Choosing microservices too early
- Choosing Rust because it sounds advanced
- Choosing Next.js for a pure backend
- Choosing WordPress for a deeply custom SaaS
- Choosing Python only because AI exists somewhere in the roadmap
- Choosing Go for a simple CRUD app
- Avoiding PHP only because it feels less modern
- Mixing five languages before there is a real reason
- Ignoring who will maintain the system
- Resume-driven development: choosing a technology because the developer wants to learn it or add it to their CV, not because it fits the project
- Premature optimization: building Kubernetes, microservices, or event-driven architecture for a product that has not yet found product-market fit
- Choosing serverless by default when a VPS is cheaper, simpler, and already available
- Adding a vector database or AI orchestration framework before confirming that embeddings or complex agent workflows are actually required
